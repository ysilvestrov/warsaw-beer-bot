# Браузерне розширення «Warsaw Beer Overlay» — встановлення та налаштування

Розширення накладає на сторінки крафтових магазинів твій особистий статус
**«вже пив»** і **твою оцінку** для кожного пива, яке збігається з твоєю історією
Untappd. Підтримувані магазини згруповано за країною, з якої вони відправляють
замовлення:

- **Україна:** [BeerFreak](https://beerfreak.org/),
  [WineTime](https://winetime.com.ua/), [Flasker](https://flasker.com.ua/)
- **Польща:** [OneMoreBeer](https://onemorebeer.pl/),
  [Piwne Mosty](https://piwnemosty.pl/), [Funkyshop](https://funkyshop.pl/)
- **Нідерланди:** [Beer Republic](https://beerrepublic.eu/),
  [Bierloods22](https://bierloods22.nl/en/), [Hoptimaal](https://hoptimaal.com/en/)
- **Чехія:** [Beershop](https://beershop.eu/) — один магазин із мовними версіями
  `beershop.pl`, `beershop.cz`, `beershop.sk`, `beershop.eu` і `beershop.de`

Щоб усе запрацювало, потрібні три речі: (1) завантажити свою історію пив у бота,
(2) отримати токен доступу, (3) встановити й налаштувати розширення. Нижче — по кроках.

### Що видно без токена

Розширення працює навіть **без токена**: на сторінках магазинів показуються
**глобальні рейтинги Untappd** (бейдж ⭐) і посилання на пиво/пошук. Це дозволяє
одразу побачити, як воно працює.

Персональні можливості вмикає **токен** (Частина 2): бейдж ✅ «ти вже це пив» із
**твоєю** оцінкою, ❓ для ймовірних збігів, а також пошук відсутніх пив і
синхронізація чекінів. Popup розширення підкаже «Not connected» (англійський
інтерфейс), поки токен не додано.

---

## Передумови

- Браузер на базі Chromium: **Chrome, Edge, Brave або Opera** (розширення формату MV3).
- Акаунт **Untappd** з історією чекінів (бажано Supporter — щоб експортувати історію).
- _Node.js потрібен лише розробникам, що збирають із сорсів (див. примітку в Частині 2)._

## Частина 1. Реєстрація в боті та завантаження списку пив

Це робиться **один раз** у Telegram-боті. Саме історія Untappd дає розширенню дані
про те, що ти вже пив (без неї бейджі не з'являться).

### 1.1. Запустити бота й обрати мову

1. Відкрий бота в Telegram, надішли **`/start`**.
2. За потреби зміни мову: **`/lang`**.

### 1.2. Прив'язати акаунт Untappd

Надішли:

```
/link <username>
```

де `<username>` — твій нік в Untappd (можна повний URL `untappd.com/user/<username>`).
У відповідь: `✅ Прив'язано до untappd.com/user/<username>`.

### 1.3. Завантажити історію пив (імпорт) — це і є «список пив»

1. Надішли команду **`/import`**.
2. Бот попросить файл експорту з Untappd: **CSV, JSON або ZIP (до 20 MB)**.
3. Де взяти експорт: в Untappd → **Supporter → Account → Download History**.
   - Якщо JSON великий (> 20 MB) — **запакуй його в ZIP** (стискається приблизно в 10×)
     і надішли ZIP: Telegram не дасть боту скачати файл більший за 20 MB.
4. Надішли файл боту як **документ** (вкладення, не текст).
5. Бот покаже прогрес і завершить: `✅ Імпортовано N чекінів`.

Після цього бот знає, що саме ти пив і як оцінив — це й використає розширення.

> Можна оновлювати історію будь-коли, надіславши новий експорт через `/import`.

### 1.4. Отримати токен доступу для розширення

Надішли:

```
/extension
```

Бот відповість інструкцією та токеном у вигляді копійованого блоку
(`<code>…</code>`), **адресою API** і **посиланням на Chrome Web Store**.
Zip-файлів бот більше не надсилає.

> **Важливо:** токен ротується **1:1** — кожен виклик `/extension` створює новий токен
> і **анулює попередній**. Якщо колись зробиш `/extension` ще раз, не забудь оновити
> токен у налаштуваннях розширення.

Скопіюй токен — він знадобиться в Частині 3.

## Частина 2. Встановлення розширення

Розширення встановлюється **з Chrome Web Store** — збирати з сорсів **не потрібно**,
і бот **більше не надсилає zip-файли**.

### 2.1. Встановити зі стору

Відкрий сторінку розширення й натисни **«Add to Chrome» / «Додати в Chrome»**:

```
https://chromewebstore.google.com/detail/fdelmnhijeiojadcaihfdpecfcldbndg
```

> **Якщо бачиш «This item is not available» / «Item not available»** — залогінься
> в Google-акаунт у браузері й онови сторінку. Розширення позначене як **18+**
> (пивна тематика), тому стор ховає його від незалогінених відвідувачів і не
> показує в пошуку. За прямим посиланням воно доступне будь-кому залогіненому.

Розширення з'явиться у списку. Закріпи його іконку на панелі (необов'язково, але зручно).

### 2.2. Оновлення

Оновлення приходять **автоматично** — Chrome сам підтягує нові версії зі стору.
Нічого качати, розпаковувати й перезавантажувати не треба.

> **Переходиш зі старої unpacked-версії?** Встав токен в Options (Частина 3) і
> **видали стару копію** в `chrome://extensions`. Токен той самий — його не треба
> перевидавати: він не прив'язаний до ID розширення й поки що працює в обох копіях
> одночасно. Стару копію варто прибрати, бо дві встановлені версії малюватимуть
> бейджі на тій самій сторінці магазину й дублюватимуть одна одну.

> **Для розробників: збірка з сорсів.** Якщо хочеш зібрати сам:
> `cd extension && npm install && npm run build` → завантаж `extension/dist/`.
> Той самий `npm run build` кладе поруч архів
> `extension/warsaw-beer-overlay-<версія>.zip`.

## Частина 3. Налаштування розширення

На самій сторінці налаштувань угорі є посилання **«Read the setup guide →»**,
яке веде назад до цієї інструкції — зручно, якщо ти потрапив на Options,
не бачивши гайд раніше.

1. Відкрий сторінку налаштувань розширення:
   - правий клік по іконці розширення → **«Параметри» / «Options»**, або
   - `chrome://extensions` → у картці розширення → **«Деталі» → «Параметри розширення»**.
2. У поле **«Token»** встав токен, отриманий від бота (`/extension`).
3. Поле **«API URL»** залиш за замовчуванням:
   `https://beer-api.ysilvestrov-ai.uk`
   (зміни лише якщо в тебе власний інстанс API).
4. _(Необов'язково)_ Постав галочку **«Find missing beers via Untappd (uses your Untappd
   session)»** — тоді розширення **дошукуватиме** пиво, якого ще немає в каталозі бота,
   **через твою власну Untappd-сесію/IP**: бот повертає параметри пошуку, а розширення
   робить браузерний запит до публічного Algolia API Untappd і відправляє боту тільки JSON
   з кандидатами. Пошук обмежено кількома запитами на сторінку, з повагою до
   анти-бан-лімітів. Браузер попросить дозвіл на доступ до `untappd.com` і
   `*.algolia.net` — погодься.
   За замовчуванням **вимкнено**.

   > **Окремо від цієї галочки, для Flasker.** На сторінках `flasker.com.ua` розширення
   > і без цього дозволу автоматично відкриває у фоні сторінку кожного нового товару
   > (до 20 за одне завантаження сторінки), щоб зчитати броварню й посилання на
   > Untappd, які магазин публікує на сторінці самого товару. Запити йдуть лише на сам
   > `flasker.com.ua` — новий дозвіл браузера для цього не потрібен. Завдяки цьому
   > пиво, яке магазин напряму лінкує на Untappd, матчиться точно, а бейдж, що раніше
   > вказував на чуже пиво, тепер може виправитися сам.
5. Натисни **«Save»**.
   - Якщо ти змінив URL на нестандартний, браузер запитає дозвіл на доступ до цього
     хоста — погодься, інакше розширення не зможе звертатися до API.
6. Натисни **«Test connection»**:
   - **✅ Connected** — усе гаразд.
   - **❌ Failed (health)** — недоступний API/URL (перевір адресу та інтернет).
   - **❌ Failed (unauthorized)** — невірний або застарілий токен (зроби `/extension` ще раз).
   - **❌ Failed (network)** — браузер не зміг звернутися до API: немає дозволу на хост
     (для нестандартного URL) або немає мережі.
   - **❌ Failed (server)** — тимчасова помилка сервера, спробуй пізніше.

## Частина 4. Використання

1. Відкрий будь-який магазин зі списку вище — напряму або через каталог
   **«Supported shops»** у popup, описаний нижче.
2. Розширення **автоматично** зчитує сітку пив на сторінці, надсилає її боту на звірку
   й малює **кутовий бейдж** на картках. Що означають бейджі:

   | Бейдж | Що означає |
   |---|---|
   | **✅** (з оцінкою, напр. `✅ 4.2`) | ти **вже пив** це пиво — показано **твою** оцінку; **клік відкриває Untappd** (або пошук, якщо ще немає Untappd-сторінки) |
   | **❓** (з оцінкою, напр. `❓ 4.1`) | ти, **ймовірно**, вже пив це пиво, але збіг неточний (fuzzy); показано **глобальний** рейтинг (якщо є); **клік відкриває Untappd** для перевірки (або пошук Untappd, якщо Untappd-id ще немає) |
   | **⭐** (з оцінкою, напр. `⭐ 4.1`) | ти ще не пив, пиво є на Untappd — показано **глобальний** рейтинг; **клік відкриває Untappd** |
   | **⚪** | пиво зматчене як orphan (ще без Untappd-сторінки/рейтингу); **клік відкриває пошук Untappd** із підставленою назвою |
   | **⏳** | триває дошук на Untappd (лише якщо ввімкнено «Find missing beers…» — Частина 3, крок 4) |
   | _(без бейджа)_ | пиво не вдалося зматчити з каталогом |

3. Це працює і для SPA-навігації: коли магазин перемальовує список (фільтри, пагінація),
   накладка оновлюється сама.

> **✅ + твоя оцінка** з'являються лише для пив із твоєї історії (потрібен `/import`,
> Частина 1). **⭐ глобальний рейтинг** показується і для пив, яких ти ще не пив, якщо
> вони вже є в каталозі бота. **❓** — пиво, ймовірно, зі своєї історії, але збіг нечіткий:
> перевір на Untappd (клік по бейджу).

### Кнопка розширення на панелі (popup)

Клік по іконці розширення на панелі браузера відкриває невелике меню. Кнопки
розташовані **за важливістю** — головна дія вгорі, службова внизу:

  <img src="../assets/popup-supported-shops-collapsed.png"
       alt="Popup розширення зі згорнутим рядком Supported shops"
       width="284" height="233" loading="lazy">
  <figcaption>Каталог магазинів лишається компактним, доки він не потрібен.</figcaption>
</figure>

- **«Sync my check-ins»** (велика бурштинова кнопка вгорі) — підвантажує твої чекіни
  з Untappd (див. нижче). Це головна дія popup'а. Поки синхронізація йде, кнопка
  сіра й неактивна, а рядок під нею рахує (`Syncing… 1200 / 8200`) — це означає
  «працюю», а не «зламалось».
- **«Refresh this page»** (кнопка з контуром) — скидає кеш накладки для **поточної**
  сторінки й перемальовує бейджі наново (зручно, якщо магазин підвантажив нові позиції
  або ти щойно зробив `/import`). Результат з'являється в підписі під кнопкою: якщо
  розширення не знайшло на сторінці жодної картки пива — `Nothing to refresh — no
  beers found on this page.`, а якщо знайшло — `Refreshed — 3 beers will be
  rechecked.`. На сторінці, яку розширення не підтримує, кнопка **сіра й неактивна**,
  а той самий підпис пояснює чому — і це пояснення більше не зникає, якщо потім
  натиснути «Clear all cache».
- **«Supported shops · 10»** — натисни цей рядок, щоб розгорнути або згорнути
  каталог. Магазини згруповано за країною відправлення. Натисни магазин, щоб
  відкрити його в окремому активному вікні браузера; якщо браузер не може створити
  вікно, розширення відкриє нову вкладку. Beershop показано один раз, а його адреса
  обирається за найкращою сумісністю з мовами браузера.
- **«Clear all cache»** (сіра кнопка внизу, під тонкою лінією) — чистить **увесь**
  локальний кеш накладки (усі сайти). Просить підтвердження: перший клік показує,
  скільки записів піде (`Clear cache for 412 entries?`), другий чистить і звітує
  (`Cleared 412 entries.`) — рядком **під самою кнопкою**. Передумав — просто закрий
  popup, нічого не станеться.

Якщо токен ще **не заданий**, popup, крім звичних кнопок вище, ще показує
нотатку «Not connected» поруч із кнопкою **«Get a token»** та посиланням
**«Read the setup guide →»**. Ці додаткові елементи зникають, щойно ти
додаси токен (Частина 3).

Popup підхоплює **тему браузера**: у темній темі він теж темний.

### «Sync my check-ins» — синхронізація чекінів без Supporter

Кнопка **«Sync my check-ins»** у popup'і завантажує твою історію чекінів **прямо з твоєї
Untappd-сесії** в браузері й відправляє її боту — це альтернатива `/import`, для якої **не
потрібен Untappd Supporter**.

- **Передумова:** спочатку прив'яжи акаунт у боті — `/link <username>`. Без цього кнопка
  покаже «Link your Untappd account in the bot first (/link)».
- **Перший раз** браузер попросить дозвіл на доступ до `untappd.com` (щоб читати твою
  стрічку в твоїй сесії) — натисни **Allow/Дозволити**. Якщо відмовиш, побачиш «Allow access
  to untappd.com to sync your check-ins.» і синхронізація не почнеться.
- **Що робить:** гортає твою стрічку чекінів від найновіших до старіших і доливає в бота ті,
  яких ще немає. Прогрес видно тут же: `Syncing… 1200 / 8200`.
- **Кілька запусків для великої історії:** за один прогін підвантажується обмежена кількість
  сторінок. Якщо чекінів багато, кнопка стане **«Continue — 3200 left»** — натисни її,
  щоб почати наступний обмежений прогін. Кожен наступний запуск **продовжує глибше**, а не
  починає спочатку. Під час прогону та сама кнопка стає **«Stop»**. Коли все підвантажено —
  **«✓ Fully synced»**.
- **Кому навіщо:** Supporter'у — швидко долити нові чекіни (напр. після фестивалю, де ти
  пробував по 30+ пив на день, а серверний фон бере лише 25); не-Supporter'у — взагалі
  залити свою історію.
- Якщо Untappd почав лімітувати запити — побачиш **«Untappd is rate-limiting — try again
  later.»**; просто спробуй пізніше (вже залите не загубиться).

## Усунення несправностей

| Симптом | Що зробити |
|---|---|
| `Test connection` → **health** | Перевір поле «API URL» і доступ до інтернету/тунелю. |
| `Test connection` → **unauthorized** | Токен застарів або невірний. Зроби `/extension`, встав новий токен, **Save**. |
| `Test connection` → **network** | Браузер не дотягнувся до API: для нестандартного URL дай дозвіл на хост (**Save** ще раз або `chrome://extensions → Деталі`); перевір мережу. |
| Бейджі не з'являються | 1) Ти на підтримуваному сайті зі списку вище? 2) Чи зроблено `/import`? 3) Перезавантаж сторінку. |
| Зробив `/extension` повторно — перестало працювати | Старий токен анульовано. Встав **новий** токен у налаштуваннях і **Save**. |
| Змінив API URL — не фетчить | Під час **Save** браузер просить дозвіл на хост — погодься (або додай дозвіл у `chrome://extensions → Деталі`). |

## Коротко (швидкий старт)

1. У боті: `/start` → `/link <username>` → `/import` (надіслати експорт Untappd) → `/extension` (скопіювати токен; бот дасть і посилання на стор).
2. Встанови розширення зі стору:
   `https://chromewebstore.google.com/detail/fdelmnhijeiojadcaihfdpecfcldbndg`
   (побачив «Item not available» — залогінься в Google і онови сторінку).
3. Options розширення → встав токен → Save → Test connection → ✅.
4. Зайди на підтримуваний магазин — бейджі «вже пив» + оцінка з'являться самі.
5. Оновлення приходять самі зі стору — качати нічого не треба.
