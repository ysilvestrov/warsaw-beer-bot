# Фестивальний режим: робочі брифи

Інструкція для учасників — `docs/USER-GUIDE.md`, розділ `/fest`. Тут — те, що власник
віддає агентам (Codex на хості, будь-яка LLM) до фесту, під час нього й після.

| Коли | Файл | Кому | Що дає |
|---|---|---|---|
| За 1–3 дні до фесту і в день відкриття | `host-readiness-brief.md` | Codex на прод-хості, лише читання | Чи задеплоєно, чи цілі схема й дані фесту, чи виконано ручні кроки (`.env`, OAuth-файл MCP), чи живий MCP-шлях і чи нема `bad_shape` |
| Коли є карти поверхів | `stands-csv-llm-brief.md` | Будь-яка LLM з картами й списком секцій | CSV `секція;поверх;стенд` для `/fest stands` |
| Після останньої сесії | `post-fest-analysis-brief.md` | Codex на прод-хості, лише читання | Алерти, запізнення очей, журнал, черга й друк, статус — сировина для issue |
